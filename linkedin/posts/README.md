# Posts

One file per post, named `<yyyy-mm-dd>-<slug>.md`, started from [`../brief-template.md`](../brief-template.md). Images sit next to it as `post-<yyyy-mm-dd>-<slug>.png`.

Before drafting a new post, read the metadata of the last three to keep hook shape, type and image mode varied (see [`../originality.md`](../originality.md), section 3).
